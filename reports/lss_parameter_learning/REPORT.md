# Прогноз параметров физической модели: первый эксперимент

Использованы 261 температурных серий, 49 групп молекул с предварительным сопоставлением структур.
Все температуры одной молекулы исключались из обучения вместе. Проверяем log10(k) на отложенных составах для невиденных молекул.

MAE log10(k): **0.249**. Простой ориентир (медианные параметры обучающих веществ при той же температуре): **0.529**.
Средняя ошибка с равным весом молекул: 0.276.
Ошибка 0.3 в log10(k) означает примерно двукратное расхождение k; это не минуты и не ошибка tR.

| Вещество | Проверочные составы × температуры | MAE log10(k) |
|---|---:|---:|
| caffeine | 6 | 0.687 |
| methylparaben | 18 | 0.091 |
| ketoprofen | 18 | 0.185 |

Результат исследовательский: структуры требуют проверки, колонка и растворитель только одни. Перенос на выбранный метод TFV/FTC не проверен. Основная модель и выбранный градиент не изменены.
