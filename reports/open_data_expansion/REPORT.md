# Расширение открытых данных

Полный индекс: 2870 сигналов U Liège (13.47 ГБ). Загружено и проверено 306 QC-сигналов (1.86 ГБ).

Разобрано 306 хроматограмм; получено 917 кандидатов ширины на половине высоты и 611 оценок Rs для соседних QC-компонентов одной инъекции.

С авторской таблицей по хронологии и проверке tR связаны 282 инъекций. Это смесь урацила, 3-цианопиридина и ибупрофена. Идентификация пиков предполагаемая, по известному составу и диапазонам tR; автоматическая интеграция требует проверки. Ширина измерена относительно локальной линейной базовой линии; Rs рассчитан по формуле 1,18·ΔtR/(wh1+wh2). Это не авторские опубликованные значения Rs. Все новые метки сохраняются с training_ready=false. Отдельного прогноза Rs ещё нет.

Лицензированные полные тексты: 15; отложены из-за лицензии: 11. Извлечены 67 таблиц и 227 фрагмент с численными параметрами, включая 22 упоминаний целевых веществ. Это контекст для курирования, а не автоматически подтверждённые измерения.

## Дополнительные наборы сигналов

- zenodo_10082436: downloaded_not_normalized, 844 файлов внутри архивов.
- zenodo_14236878: downloaded_not_normalized, 17 файлов внутри архивов.
- figshare_22182694: downloaded_not_normalized, 75 файлов внутри архивов.

Они полезны для проверки обработки сигналов, но не доказывают перенос удерживания на TFV/FTC. Их содержимое ещё не нормализовано в обучающие наблюдения.

Из статьи PMC12216858 отдельно сохранены 2 авторских значения Rs (4,73 и 7,32) для FTC/DAC/LDV и 3 строки с tR, tailing, N и k. Это сводные параметры метода, не новая подтверждённая инъекция. Значения RSD% при проверке робастности не преобразуются в абсолютный Rs. Коэффициент k взят из таблицы авторов; измеренный t0 по нему не выдумывается.

## Что пока отсутствует

Смешанные хроматограммы TFV/FTC, проверенные близкие/перекрывающиеся пики, ручная проверка интеграции и независимый тест прогноза Rs. QC-пики широко разнесены, поэтому они не покрывают сложные разделения. Текущая точность CatBoost этим сбором не изменена; новые данные не подмешаны в обучение автоматически.
