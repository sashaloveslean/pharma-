# Прогноз параметров физической модели: первый эксперимент

Использованы 500 температурных серий, 94 групп молекул с предварительным сопоставлением структур.
Все температуры одной молекулы исключались из обучения вместе. Проверяем log10(k) на отложенных составах для невиденных молекул.

MAE log10(k): **0.183**. Простой ориентир (медианные параметры обучающих веществ при той же температуре): **0.492**.
Средняя ошибка с равным весом молекул: 0.200.
Ошибка 0.3 в log10(k) означает примерно двукратное расхождение k; это не минуты и не ошибка tR.

| Вещество | Проверочные составы × температуры | MAE log10(k) |
|---|---:|---:|
| caffeine | 6 | 0.442 |
| methylparaben | 18 | 0.236 |
| ibuprofen | 18 | 0.414 |
| ketoprofen | 18 | 0.145 |

Результат исследовательский: структуры требуют проверки, колонка и растворитель только одни. Перенос на выбранный метод TFV/FTC не проверен. Основная модель и выбранный градиент не изменены.

Сопоставимая проверка: 794 одинаковых случаев с сохранёнными тестовыми группами. Предыдущая MAE: 0.24934613094948294; новая: 0.2132496222775549. Одновременно изменились охват обучения и фильтрация структур.
